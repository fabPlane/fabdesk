# Google Antigravity in FabDesk

1. On the machine running FabDesk Core, install [Google's Antigravity CLI](https://antigravity.google/docs/cli-getting-started). The desktop Antigravity app is optional. Check that `agy acp --help` works.
2. Sign in on that machine with `agy acp --login`. FabDesk does not collect the Google credentials.
3. In FabDesk, open **Agent & model → Google Antigravity** and choose a model reported by the signed-in account. Choose **Agent setting** to use Antigravity’s own default. Use **Settings → Agents → Google Antigravity** to set a FabDesk default or refresh the model list after signing in or changing accounts. The picker shows model families; Antigravity controls the thinking level for a family choice. If FabDesk cannot find the CLI, set its binary path under **Agents** (typically `~/.local/bin/agy` on macOS).

FabDesk connects over [ACP](https://antigravity.google/docs/cli/acp/) and supplies its project tools through the per-run HTTP MCP connection. It streams responses and tool activity and can reload a prior Antigravity conversation. It starts the CLI with terminal sandbox restrictions enabled. Antigravity runs in FabDesk's **Run without approval** mode, the only mode this harness supports. In that mode FabDesk answers a permission request that offers a single one-time allow option by allowing it, without showing an approval card. This covers Antigravity's native file and command requests as well as FabDesk's own project tools, so use it only on projects where you accept that. FabDesk does not change the CLI's own permission rules: it never starts the CLI with permissions skipped, and Antigravity still decides which actions it asks about. A request with no one-time allow option, or with several that are not a question, is left unanswered rather than guessed. Fixed-choice questions become answer cards; Antigravity only accepts a listed choice through this interface. FabDesk's strict Supervised and planning-only modes are not supported by this harness. If you select Antigravity from **New idea**, FabDesk asks you to name and create a project before sending your prompt. To discuss an idea without creating a project, use Codex or Claude.

Antigravity can ask before using MCP tools, even read-only ones. Google documents [exact tool allow rules](https://antigravity.google/docs/cli/mcp/#mcp-permissions-and-access-control), but `agy` 1.5.16 still requested approval for FabDesk’s project status tool over ACP in our test. FabDesk answers those requests as described above and does not change Antigravity's native approval settings; you do not need to turn on blanket approval in Antigravity itself.

Model availability, personal settings, installed extensions, and any other tool integrations remain under Antigravity's control. The normal Antigravity service receives your prompts and any project context the CLI collects. Start with a disposable project if you want to test that setup before opening your own work.
